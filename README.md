# Mellow Soap — เว็บไซต์ขายสบู่ 2 SKU

โปรเจกต์ตัวอย่างสำหรับงานเรียน มีหน้า Landing Page, แบบฟอร์มสั่งซื้อ, รูปสินค้าแยกโฟลเดอร์ และ Google Apps Script สำหรับบันทึกคำสั่งซื้อใน Google Sheets

## ไฟล์สำคัญ
- `index.html` — หน้าเว็บไซต์ขายสบู่
- `style.css` — ตกแต่งเว็บไซต์และรองรับมือถือ
- `script.js` — เลือกสินค้า คำนวณราคา และส่งคำสั่งซื้อ
- `images/` — รูปสินค้าสอง SKU (แยกโฟลเดอร์)
- `google-apps-script/Code.gs` — โค้ดเชื่อม Google Sheets

## สินค้าในตัวอย่าง
| SKU | สินค้า | ราคา |
|---|---|---:|
| MS001 | Milk Soft Soap | 89 บาท |
| MS002 | Honey Glow Soap | 99 บาท |

แก้ชื่อสินค้า ราคา และรายละเอียดได้ใน `index.html` และ `script.js` ให้ตรงกับสินค้าจริง

## ขั้นตอนที่ 1: สร้าง Google Sheets
1. เข้า https://sheets.google.com แล้วกดสร้างสเปรดชีตเปล่า
2. ตั้งชื่อ `Mellow Soap Orders`
3. เปิดเมนู **ส่วนขยาย (Extensions) > Apps Script**
4. ลบโค้ดเดิมใน `Code.gs` แล้วคัดลอกโค้ดจากไฟล์ `google-apps-script/Code.gs` ในโปรเจกต์นี้ไปวาง
5. กดบันทึก (รูปดิสก์)
6. กด **Deploy > New deployment**
7. เลือกชนิด **Web app**
8. ตั้ง **Execute as: Me** และ **Who has access: Anyone** แล้วกด Deploy
9. อนุญาตสิทธิ์ตามหน้าจอ แล้วคัดลอก URL ที่ลงท้ายด้วย `/exec`

> URL นี้เป็นปลายทางรับคำสั่งซื้อ อย่าโพสต์ URL ในที่สาธารณะโดยไม่จำเป็น

## ขั้นตอนที่ 2: ใส่ URL ลงเว็บไซต์
1. เปิดไฟล์ `script.js`
2. หาบรรทัด `const GOOGLE_SCRIPT_URL = "ใส่_URL_GOOGLE_APPS_SCRIPT_ที่นี่";`
3. แทนข้อความด้านในด้วย URL `/exec` ที่คัดลอกมา โดยคงเครื่องหมายอัญประกาศไว้
4. กด Save

## ขั้นตอนที่ 3: อัปโหลดขึ้น GitHub
1. เข้า https://github.com และเข้าสู่ระบบ
2. กดปุ่ม **New repository** ตั้งชื่อ `mellow-soap-store`
3. กด **Create repository**
4. อัปโหลดไฟล์และโฟลเดอร์ทั้งหมดจากโฟลเดอร์โปรเจกต์นี้ โดยต้องคงโฟลเดอร์ `images` และ `google-apps-script` ไว้
5. กด **Commit changes**

## ขั้นตอนที่ 4: นำขึ้น Vercel
1. เข้า https://vercel.com แล้วเข้าสู่ระบบด้วย GitHub
2. กด **Add New > Project**
3. เลือก Import โปรเจกต์ `mellow-soap-store`
4. Framework Preset เลือก **Other**; Build Command และ Output Directory เว้นว่างได้
5. กด **Deploy**
6. เมื่อเสร็จจะได้ URL เว็บไซต์ `.vercel.app`

## ขั้นตอนที่ 5: ทดสอบคำสั่งซื้อ
1. เปิดเว็บไซต์จาก URL Vercel
2. ทดลองสั่งซื้อโดยใช้ข้อมูลทดสอบที่ไม่ใช่ข้อมูลส่วนตัวจริง
3. เปิด Google Sheets แท็บ `Orders` ตรวจว่ามีแถวคำสั่งซื้อใหม่
4. ตรวจ SKU จำนวน ราคาต่อชิ้น ยอดรวม ชื่อ เบอร์โทร ที่อยู่ และรหัสไปรษณีย์ให้ถูกต้อง

## ขั้นตอนหยิบสินค้า แพ็ก และจ่าหน้าพัสดุ
1. เปิด Google Sheets แท็บ `Orders`
2. ดู SKU และจำนวนในรายการคำสั่งซื้อ เช่น `MS001` จำนวน 2 ชิ้น
3. หยิบสินค้าตาม SKU และตรวจจำนวนให้ตรงกับคำสั่งซื้อ
4. แพ็กสินค้าให้เรียบร้อย
5. คัดลอกชื่อผู้รับ เบอร์โทร ที่อยู่ และรหัสไปรษณีย์ไปสร้างใบจ่าหน้าในระบบของบริษัทขนส่ง
6. หลังส่งพัสดุ ให้เพิ่มคอลัมน์ `เลขพัสดุ` และ `สถานะจัดส่ง` ใน Google Sheets เพื่อบันทึกเลขติดตามและเปลี่ยนสถานะเป็น `จัดส่งแล้ว`

## ข้อจำกัดที่ควรรู้
- ตัวอย่างนี้บันทึกคำสั่งซื้อใน Google Sheets แต่ยังไม่มีระบบรับชำระเงิน
- ยังไม่ได้เชื่อม API บริษัทขนส่ง จึงต้องสร้างใบจ่าหน้าผ่านระบบขนส่งเอง
- Google Sheets เป็นหน้าจัดการออเดอร์สำหรับผู้ขาย; อย่าเปิดเผยชีตที่มีชื่อ ที่อยู่ และเบอร์โทรของลูกค้าเป็นสาธารณะ
- ก่อนใช้ขายจริง ควรเพิ่มการตรวจสอบคำสั่งซื้อฝั่งเซิร์ฟเวอร์ ระบบป้องกันสแปม และประกาศความเป็นส่วนตัว
